# emacs.d.3

The third incarnation of my Emacs configuration.

## Requirements

- Linux or macOS.
- Emacs >= 31.0.50

## Installation

1. Install additional dependencies:

> > :construction: Only macOS with homebrew and Fedora Linux supported:

   ```bash
   make deps
   ```

1. Install the project:

   ```bash
   make install
   ```
